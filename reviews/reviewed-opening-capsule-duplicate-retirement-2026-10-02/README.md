# Reviewed retirement of two duplicate scratch encodings

This is a conditional storage decision, with no cleanup performed by publication. The f912 and ce0f game evidence archives remain needed and are retained in their exact canonical GitHub copies. Independent comparison verifies complete byte equality and member coverage; independent retention review prefers those durable copies and finds the extra private scratch encodings unnecessary for the known current workflow. Root judges their selective retirement useful because disk capacity blocks the next opening-session comparison.

[LOCATION-MAP.json](LOCATION-MAP.json) preserves the exact old scratch paths, SHA256, sizes and physical metadata, and points to the canonical copies. Historical indexes and readers still name scratch paths: they must use this append-only map or a separately reviewed exact-byte reconstruction at a missing path. This does not restore old inode/time/write isolation or promise every historical reader works unchanged. Related scratch indexes, receipts, source, art, reviews, datasets and all canonical versions stay. The review used bounded known consumer scans, not universal absence claims.

The original Root deletion method was rejected because optimized Python erased its safety assertions and its network check lacked a timeout. Both original method and rejection remain unchanged. The revised method explicitly refuses optimized Python, uses a fresh confirmed push receipt, validates exact two-path namespace/body/metadata/nlink relationships, records PRE before deletion and checks each canonical replacement afterward. Separate source acceptance is conditional; a new current clean push, Root grant, actual bounded action and independent POST are still required. [PRODUCER-DECISION.json](PRODUCER-DECISION.json) records this judgment before any action.

The native checkpoint publication review is preserved here separately so the already reviewed87-file archive directory stays unchanged. No playable-source, release, quality, platform or human-enjoyment claim follows from storage work.
