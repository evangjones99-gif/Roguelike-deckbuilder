# Relic discovery author proposal

The UI-only agent campaign had to open the deck to find earned relic effects. This separate main-only proposal turns existing map/outcome relic names into focusable inspection controls and shows the same controls at reward. Each opens its own truthful catalogue effect in the existing modal, with ownership checked before opening and normal modal focus restoration. It changes no catalogue, acquisition, save, combat or feedback rule. No additional top-bar control crowds the fight. Existing battle Deck inspection remains available.

Baseline is separately frozen scene/jaw efef7131 at version0.9; this is not part of that reviewed candidate. Actual reward/mobile layout, keyboard/controller navigation, unchanged saves and display need verification before independent promotion. No build, playtest or acceptance is yet claimed.
