## Capacity, host and remaining limits

Acceptance covers independently tested code/provenance/transaction behavior, not an unlimited-size archive transaction or minimum disk/RAM requirement. Every future real bundle milestone must preflight **both durable output and temporary verification ZIP/fresh bare restore space**, account for concurrent allocations, retain margin and verify its final exact clean commit/archives. The owner's current default ZIP milestone is separate and is not held for this proposal.

Utility needs the existing local Linux development-host Git, Python3, Node and ZIP/tar/ASAR tools. No Windows release-host or consumer Git/Python requirement is established.
