On Win32, dirname of `dist/art/PROVENANCE.json` is still `dist/art`, while sep is backslash; the string is treated as one header key instead of two directories. The method even creates a phantom `dist/art` directory in its cached in-memory header. It then looks for PROVENANCE.json under that empty directory and throws. This does not alter the archive's stored bytes. A single-directory `dist/build-provenance.json` works incidentally because dirname is only `dist`; it still should use the same native boundary.
