# Independent TMP-only stock runtime capacity proposal

**Accepted as a concrete proposal, conditional on reader release and root's separate full transfer gate. No consolidation occurred.** I SHA-256 hashed all **942** regular files and inventoried all **39** directories across 13 actual TMP-only native package/comparison trees. Every member's size/mode/device/inode/nlink/mtime/ctime remained unchanged during its read; atime may change from reads and is separately recorded before/after. Full tree memberships were checked. The audit excludes all workspace/source paths and never modifies a package or archive.

Restricting candidates to explicit root Electron runtime filenames and locales/*.pak finds **140** complete same-byte/same-size/same-POSIX-file-mode duplicate groups. Grouping these after reader release can save **1,463,070,994 logical bytes /1,464,025,088 currently allocated bytes incrementally**, after counting each already-shared device/inode only once. Existing nlink values exactly equal observed aliases across the complete 13-tree inventory; no outside-inventory alias was found. This is a forecast from actual inode/block records, not measured reclamation. Actual TMP free at audit was **1,168,093,184 bytes**; inferred additional capacity depends on a later root operation and other writers.

The exact package trees are the original v0.7 Linux/Windows comparison roots; combined45bd/width23477 named Linux roots; previously retained v0.6.1 Linux/Windows roots; and seven already retained v0.3–0.5 TMP comparison roots. Directory names describe location, not a new version/quality certification. Full current file hashes including excluded ASAR files are inventoried for post-operation preservation checks; no ASAR member is proposed for sharing.

**Hardlink eligibility is deliberately limited:** explicit stock runtime root leaves (runtime executables, stock libraries, pak/bin/dat/vendor JSON and Electron/Chromium license files) and exactly two-level locales/*.pak. Entire resources subtrees, app.asar/default_app.asar, source/game HTML/CSS/JS/media/freezes, all profile/save/feedback directories, archives, datasets and unique art/review inputs are excluded. No known unique file is proposed for replacement. Every eligible group lists every path and exact content/mode identity; no basename-only or near-match comparison was used.

Root must wait until the active reader freeze—including the current width23477 playable package—is explicitly released. Root then needs a separately reviewed plan, fresh rehash before changing links, unique owned transaction links, retained per-path original metadata sidecars and complete post-consolidation verification of all 942 files and 39 directory modes/memberships. Every path must remain present with exact bytes/file mode. Do not chmod to claim read-only. Existing canonical alias choice in AUDIT.json is a forecast only, not an instruction to mutate now.

Shared inodes make future writes affect aliases. They are immutable by usage contract unless real filesystem enforcement is established. Fresh changed builds need independent files. Hardlink consolidation changes inode/nlink history and can collapse differing file mtimes; replacing links changes parent directory mtime/ctime. Preserve directory mode and every historical path, restore mtime/atime when appropriate and record unavoidable ctime/inode changes honestly; do not assert complete original lstat identity. The audit includes full original timestamps and metadata for a later comparison, while root should refresh its own metadata capture immediately before mutation.

No original official release archive is touched or used as a hardlink destination. Existing durable release/review evidence remains recovery authority; TMP is not a durable backup. This capacity finding does not certify any new source/build, controller/hardware, secure-default sandbox, native gameplay, AAA/fun, consumer/Steam install or publication claim.
