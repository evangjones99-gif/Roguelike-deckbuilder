## Measured promotion finding

**Repeat aspect changes permanently reduce dead figure scale.** `resize()` multiplies retained dead figures by `min(scaleX,scaleY)` using their already-resized size. Independent immediate resizes700×277→390×220→1398×328→502×277→700×277 preserve the same semantic death/cue timestamps and return the same Canvas dimensions, but the warleader corpse shrinks from119.11px to35.53px (29.83% of original). The five-case evidence separately shows the same effect for the dying hound84→25.05px. Whole cells remain contained and canonical rules are untouched; the visual scale accumulates irreversible losses during window/aspect changes. A stable reference for retained corpse geometry/size could allow reversible viewport reprojection without restarting death cues. Repair in a new candidate, preserve this R3 and rerun the affected resize/terminal/lifecycle gates. `resize-roundtrip-r3.json` is a negative-finding confirmation, not a passing quality gate.
