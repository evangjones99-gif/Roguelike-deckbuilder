# Isolated Windows installer experiment

This workflow builds and tests an unsigned NSIS installer on a disposable Windows2022 CI host, using the exact reviewed0.7.0/0be runtime. A random QA-only appId, GUID, executable name, installation root and explicit local profile distinguish it from production identity. It is a controlled installation experiment, not a Steam or consumer installer release.

Root selected the exact frozen R2 source after independent review of installed electron-builder26.15.3/NSIS code. The first proposal remains rejected: its uninstaller generator created the final target too early, its registry oracle miscounted shared HKCU logical views, and a stock updater-cache copy escaped the owned QA base. R2 separates generator/installation paths, redirects the compiled cache definition before expansion, checks shared aliases accurately and suppresses stock known-folder creation. Old failures/reports remain canonical under reviews/installer-v0.8-r1-*; source acceptance/native-pending records are under installer-v0.8-r2-*.

The least-privilege workflow runs only on the fixed repository/production branch, uses pinned action commits, does not accept PR input, signs or publishes nothing, and preserves failed native evidence. Committing/pushing its new path deliberately activates the owner's authorized native installation experiment. Current source/raw hashes must match the pinned29-input runtime; later audio/art runtimes require a new reviewed native candidate rather than bypassing this check.

Acceptance requires actual compilation; generator/target separation; exact installed payload/ASAR/resources/unsigned status; installed hunter drawing and canonical earned binding/command; save/reload/relaunch and optional local synthetic feedback; complete unique installation-directory/registry removal; and unchanged explicit profile, sentinel, staged package and default updater-cache inventory. A successful launcher exit alone does not establish uninstall completion. Failures retain their directory inventories and reports.

The original installer is split into individually capped24MiB parts, at most eight, with streamed full/part hashes and an explicit192MiB ceiling. Small evidence is uploaded separately. Original package/download reconstruction and final durable preservation remain required after an actual successful run; CI retention expires after30days. A source test, uploaded artifact or isolated QA pass does not establish production-identity update/migration, normal consumer profile, signing/SmartScreen, hardware controller/audio, Steam Deck or Steamworks/store readiness.
