# Hollowpact 0.4 reviewed development milestone

This reviewed development cycle repairs campaign save reliability and improves how players judge and see combat consequences. It follows the preserved known-defective v0.3 checkpoint; old versions and every finding remain intact.

- Repeated Silence against a guard now keeps one status suffix. Costs, card copies, enemy armor, RNG and all mechanical outcomes are unchanged. The complete 119-action campaign that previously made its save unreadable validates at every step and continues to victory.
- The loader can narrowly recover an affected legacy guard-label save only when the complete repaired state passes validation. It preserves the exact original text before replacing the save. Unrelated corruption remains rejected.
- Hovering or focusing a legal target previews resolved health damage, absorbed armor, recovery, retaliation and lethal consequences. Previewing does not commit actions, change saves or consume the run's RNG, and reveals no future draws/rewards.
- Contact shadows use the correct local coordinates and render before creature bodies. Painted airborne hound poses have an authored lighter/wider shadow. Solid cel changes replace the old translucent double-anatomy dissolves; sparse poses can still pop and require additional paintings.
- Build tooling invokes installed compiler/bundler entry points directly for Windows compatibility. A native Windows workflow packages with executable resources enabled and signing disabled, then launches the actual package and checks persistence, portrait, security settings and local feedback.
